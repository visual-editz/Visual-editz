VISUAL EDITZ — PREMIUM PORTFOLIO
================================

Files:
- index.html
- style.css
- script.js

CUSTOMIZE BEFORE PUBLISHING
1. Open script.js and replace WHATSAPP_NUMBER with your real WhatsApp number including country code.
2. Update INSTAGRAM_URL if your username changes.
3. In index.html, replace the four demo portfolio href="#" links with your real Instagram/YouTube/video URLs.
4. Replace the demo pricing if needed.
5. Replace the demo thumbnail backgrounds in style.css with your own images/videos if desired.
   For image thumbnails, use background-image: url("your-image.jpg") on .v1, .v2, etc.

WHATSAPP FORM
The form creates a WhatsApp message automatically. No backend or database is required.

GITHUB PAGES
Upload all 3 files to a GitHub repository. Then:
Settings -> Pages -> Deploy from branch -> main -> /root -> Save.
